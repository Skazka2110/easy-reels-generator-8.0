КАК СОБРАТЬ ПОРТАТИВНУЮ WINDOWS-ВЕРСИЮ

Что понадобится только на компьютере, где выполняется сборка:

1. Windows 10 или Windows 11, 64 бита.
2. Подключение к интернету.
3. 64-битный Python версии 3.11, 3.12 или 3.13.

Python 3.14 пока не подходит для этой версии из-за ограничения графической
библиотеки. Его не нужно удалять: Python 3.13 можно установить рядом, а сборщик
автоматически выберет подходящую версию.

Порядок сборки:

1. Полностью распакуйте исходный архив в отдельную папку.
2. Дважды щёлкните BUILD_WINDOWS.bat.
3. Не закрывайте чёрное окно. Первый запуск загружает зависимости и FFmpeg,
   поэтому может занять 10–30 минут.
4. После сообщения об успешном завершении откройте папку artifacts\windows.
5. Готовый файл называется Easy_Reels_Generator_Windows_x64_v080.zip.

Python нужен только для создания релизного архива. Покупателю Python устанавливать
не потребуется: готовая папка содержит приложение и необходимые компоненты.

Microsoft Excel покупателю не нужен. Хуки и подхуки редактируются прямо
в интерфейсе программы кнопкой «Редактировать хуки».

Если сборка завершилась ошибкой, сохраните снимок всего текста ошибки. Перед
отправкой закройте на снимке личные пути и имя пользователя Windows, если они видны.
