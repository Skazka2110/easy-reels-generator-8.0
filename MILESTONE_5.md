# Этап 5 — сервер в эксплуатации и Windows-сборка

Статус: сервер развёрнут 22 июля 2026 года; воспроизводимый Windows-комплект подготовлен.

## Сервер

- `https://license.proaistudio.pw` работает через HTTPS;
- приложение запущено отдельным системным пользователем;
- Uvicorn доступен только на `127.0.0.1:8765`;
- Nginx выполняет обратное проксирование и HTTP → HTTPS;
- SQLite и секреты закрыты правами `0600`;
- создан первый разрешённый, но ещё не привязанный тестовый ключ.

## Windows

- добавлена сборка PyInstaller `onedir` без необходимости установки Python у покупателя;
- портативное приложение автоматически использует `ffmpeg.exe` и `ffprobe.exe` рядом с собой;
- сборщик загружает FFmpeg и добавляет его в релизную папку;
- добавлены свободные шрифты Roboto с кириллицей;
- в релиз входят `hooks.xlsx`, `settings.ini`, рабочие папки и краткая инструкция;
- итоговый архив создаётся командным файлом `BUILD_WINDOWS.bat` на Windows x64.
- сборщик принимает только проверенные Python 3.11–3.13 и не запускается на 3.14.

## Ограничение проверки

PyInstaller создаёт нативный Windows-файл только при запуске на Windows. Код и
сценарий сборки проверяются автоматическими тестами в среде разработки, а сам
полученный `.exe` необходимо один раз собрать и проверить на реальном Windows-компьютере.
