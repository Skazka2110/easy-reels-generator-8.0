# Easy Reels Generator 0.6.3

Изменения тестовой версии:

- строки с подложками `lines` и `torn_paper` собираются в плотный блок;
- межстрочный промежуток масштабируется относительно итогового размера шрифта;
- фактические границы букв по-прежнему измеряются отдельно для каждого TTF/OTF;
- строки выравниваются по общей оптической высоте внутри одного блока;
- рваный край строится внутри своей полосы и не наслаивается на соседние;
- отдельная пользовательская настройка межстрочного интервала не требуется.
