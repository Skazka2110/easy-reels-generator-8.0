# Easy Reels Generator by ProAI

Рабочее приложение по ТЗ v1.0. Текущая версия ядра — 0.8.0.

## Реализованные этапы

Первая проверяемая вертикаль:

1. создание структуры портативного проекта;
2. чтение первой необработанной строки `hooks.xlsx`;
3. поиск и проверка видео/музыки;
4. создание текстовой подложки;
5. рендер одного ролика 1080×1920, 6 секунд, 30 fps;
6. проверка результата через FFprobe;
7. атомарная запись имени файла и статуса во внутренний список хуков.

Второй этап:

1. последовательная обработка всех необработанных строк;
2. однократное перемешивание и циклические очереди видео и музыки;
3. продолжение партии после ошибки отдельной строки;
4. события прогресса для будущего интерфейса;
5. безопасная остановка после текущего ролика;
6. отдельные тестовые ролики в `preview`, не меняющие список хуков и очереди партии.

Третий этап:

1. тёмный графический интерфейс с неоново-зелёным оформлением ProAI;
2. карточки состояния хуков, видео, музыки и настроек;
3. кнопки редактора хуков, настроек и папки готовых роликов;
4. понятная кнопка «Тестировать настройки»;
5. предзапусковая сводка и подтверждение массовой генерации;
6. фоновый рендер без зависания окна, прогресс и безопасная остановка;
7. итоговое окно с количеством результатов и ошибок.

Четвёртый этап:

1. одноразовая онлайн-активация бессрочного ключа;
2. локальная подписанная лицензия для дальнейшей работы без интернета;
3. привязка к отпечатку Windows/macOS-устройства;
4. защита от простого копирования активированной папки на другой компьютер;
5. один перенос после ручного разрешения администратора;
6. API активации, SQLite-база, журнал событий и веб-панель ProAI;
7. окно ввода ключа и зелёный статус активной лицензии в приложении.

Пятый этап:

1. сервер лицензий развёрнут на Ubuntu VPS и доступен по HTTPS;
2. подготовлена воспроизводимая портативная Windows x64-сборка PyInstaller;
3. в релиз автоматически добавляются локальные FFmpeg/FFprobe;
4. добавлены стартовые шрифты Roboto с кириллицей, шаблон хуков и инструкция;
5. покупателю не требуется устанавливать Python.

Шестой этап:

1. видео автоматически выбираются из `videos/top` или `videos/bottom`;
2. добавлены шрифты Montserrat, Manrope и Oswald с кириллицей;
3. хук с подхуком безопасно размещается сверху или снизу;
4. доступны эффекты `outline` и `glow` вокруг букв без сплошной подложки;
5. каждый тестовый ролик получает отдельное имя.

## Папки видео

Положение текста выбирается в окне «Настроить ролики»:

- `top` — текст сверху, видео берутся только из `videos/top`;
- `bottom` — текст снизу, видео берутся только из `videos/bottom`.

Связка «хук + подхук» поддерживает оба положения. Файлы непосредственно в
`videos` намеренно не используются, чтобы программа не выбрала подложку с
неподходящей свободной областью.

Нативный Windows-архив создаётся на Windows запуском `BUILD_WINDOWS.bat`.
Все три архива можно собрать вручную во вкладке GitHub Actions запуском
workflow `Build Easy Reels Generator`.

## Запуск ядра разработчиком

```bash
python -m easy_reels init-project ./demo
python -m easy_reels check ./demo
python -m easy_reels render-one ./demo
python -m easy_reels preview ./demo
python -m easy_reels render-all ./demo
easy-reels-gui --project ./demo
```

До сборки портативных архивов приложение запускается с `PYTHONPATH=src` либо после установки проекта в виртуальное окружение. Обычный GUI-запуск требует доступного сервера активации и действующего ключа.

Серверная часть и инструкция находятся в каталоге `server`.
