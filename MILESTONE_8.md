# Easy Reels Generator 0.8.0

## Главное

- Microsoft Excel больше не нужен ни на Windows, ни на macOS.
- Хуки, подхуки, описания и результаты редактируются во встроенной таблице.
- Можно вставить из буфера сразу несколько строк, удалить строки и сбросить
  результат для повторной генерации.
- Перед каждым сохранением редактор создаёт резервную копию `hooks.xlsx`.

## Активация

- HTTPS использует комплект доверенных сертификатов, включённый в сборку.
- Сетевые ошибки разделены на SSL, таймаут и общую ошибку соединения.
- Технические подробности сохраняются в `activation.log` без лицензионного ключа.
- Лицензия хранится в пользовательской папке и автоматически переносится
  из старой переносной папки `licenses`.

## Сборки

- Добавлена ручная сборка через GitHub Actions.
- Workflow создаёт Windows x64, macOS ARM64 и macOS Intel.
- Для macOS рабочие папки располагаются рядом с `.app`, а не внутри пакета.
- Добавлены автоматические тесты перед созданием релизных архивов.
