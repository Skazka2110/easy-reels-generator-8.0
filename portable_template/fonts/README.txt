В комплект включены свободные шрифты с поддержкой кириллицы:

- Roboto-Black.ttf — основной жирный хук;
- Roboto-Bold.ttf — подхук;
- Roboto-Medium.ttf — дополнительный вариант;
- Roboto-Regular.ttf — дополнительный вариант.
- Montserrat-Black.ttf — широкий акцентный хук;
- Montserrat-Bold.ttf — универсальный жирный вариант;
- Manrope-ExtraBold.ttf — современный акцентный хук;
- Manrope-Bold.ttf — современный вариант для подхука;
- Oswald-Bold.ttf — узкий жирный шрифт для длинных хуков;
- Oswald-Medium.ttf — узкий спокойный вариант.

Чтобы добавить свой шрифт, положите файл TTF или OTF в эту папку и укажите его
точное имя в settings.ini.

Лицензии находятся в файлах Roboto-LICENSE.txt, Montserrat-LICENSE.txt,
Manrope-LICENSE.txt и Oswald-LICENSE.txt.
