КАК СОБРАТЬ WINDOWS И macOS ЧЕРЕЗ GITHUB

1. Загрузите всё содержимое этого архива в корень репозитория GitHub.
   Папка .github тоже должна попасть в репозиторий.
2. Откройте репозиторий и перейдите во вкладку Actions.
3. Слева выберите workflow «Build Easy Reels Generator».
4. Нажмите Run workflow, затем ещё раз Run workflow в открывшемся меню.
5. Дождитесь завершения трёх заданий:
   - macOS ARM64 — для Mac с процессорами M1, M2, M3, M4 и новее;
   - macOS Intel — для старых Mac с процессором Intel;
   - Windows x64 — для 64-битной Windows 10/11.
6. Откройте завершённый запуск. Внизу страницы, в разделе Artifacts,
   скачайте нужные архивы.

Готовые сборки уже содержат Python, графический интерфейс, FFmpeg, FFprobe,
шрифты и рабочие папки. Microsoft Excel пользователям не требуется.

Сборки macOS создаются без сертификата Apple Developer. При первом запуске
пользователь может увидеть предупреждение macOS. Нужно нажать на приложение
правой кнопкой мыши, выбрать «Открыть» и подтвердить запуск.

Workflow запускается только вручную и не расходует минуты GitHub при каждом
обычном изменении исходников.
